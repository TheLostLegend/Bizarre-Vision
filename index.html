✦ THE BIZARRE FIELD GUIDE

A little guide to
the extraordinary.

Your screen deserves a Stand. Search, discover, collect — and keep scrolling. The archive is live, not an offline bundle.

01 / Speak the language of the archive

Use a keyword or Wallhaven's tags. Select a tag or color in the viewer to search for more like it.

anime a keyword
+"cyberpunk city" exact, required tag
-landscape exclude a term
@username find an uploader
type:png file format
id:123 an exact tag ID

02 / A filter for every dimension

Choose your categories, resolution, aspect ratio, color and sorting. Changes stay in a draft until you press Find your Vision or Enter in the search field. The current gallery stays put while you edit. Refresh uses the applied search. Toplist uses the selected time range; Random keeps its seed between pages.

03 / Shortcuts to another world

/ or Ctrl / ⌘ K SearchB Gallery blur← → Previous / next originalEsc Close? Help

Letter shortcuts do not run while you type in a field. In the original viewer, arrows work and Escape closes it. B cannot blur an original. Press / or Ctrl/Command+K to return to search.

04 / Infinite, but not infinite requests

More wallpapers load near the bottom. Gallery thumbnails load near your viewport; opening a wallpaper requests the full original, never a larger preview. The Download original button fetches the actual file and asks your browser to save it. If a browser or relay prevents this, use Open original file and Save image as… in your browser. A failed request has a retry, not an endless loop.

05 / Collection ≠ Wallhaven account favorites

The heart saves this wallpaper's public information in this browser's localStorage, up to 200 wallpapers. No account is required. Collection is scoped to this browser and site origin (protocol, domain and port), not an account. Another browser, device or origin has a separate collection; projects on the same origin can share local entries. Clearing site data removes it.

Only the wallpaper links and metadata are saved, not the image files. An internet connection is still required to display or download originals. The Favorites number in the inspector is the public Wallhaven community count — it is not your personal list. Your own Wallhaven favorites are not imported or synced, and Bizarre Vision on GitHub Pages has no account backend.

06 / If the connection gets bizarre

GitHub Pages cannot run a private backend. Browser CORS restrictions and unavailable relays can interrupt the archive. Use the connection indicator to inspect the live routes, retry, or supply your own HTTPS CORS relay. Public proxies are not guaranteed to stay online.
✦ STAND COMMUNICATIONS

Keep the vision alive.

Direct is fastest. HTTPS relays step in when the browser cannot read Wallhaven's API. A failed relay is paused briefly, not hammered. Only Wallhaven URLs are accepted.

Use a trusted, HTTPS GET relay whose `url=` parameter accepts an encoded target URL. No API keys are sent to third parties. Your own relay can be more reliable than a public one.

Route status reflects requests from this session, not a global uptime monitor. Public proxies may have limits, block a host, or log requests. Use a relay you trust; queries, image URLs and your IP can be visible to it. GitHub Pages deployment needs no server-side code.
